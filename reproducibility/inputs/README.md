# Frozen input package

This directory is intentionally empty in the public code repository. Before
creating the Code Ocean capsule or Zenodo archive, populate it with the exact
input files listed in `../README.md` and record SHA-256 checksums in
`input_checksums.tsv`.

Do not add private sample information or local workstation paths. Genome
assemblies should be represented by public accession identifiers and the
metadata required by the manuscript. Large raw assemblies and annotation
databases may be deposited separately; the capsule should contain the frozen
processed inputs needed to regenerate figures and tables.
